# AniShelf 简介

**当前已上线 App Store，欢迎下载体验：[App Store 链接](https://apps.apple.com/app/id6759359144)。新功能将先在 TestFlight 发布，后续再推送到 App Store。TestFlight 链接：[AniShelf TestFlight](https://testflight.apple.com/join/ns3sR38X)。**

AniShelf 主要用来追踪、记录、管理看过的番剧/动画电影。核心功能：

- 从 TMDb 获取番剧/动画电影数据，展示在 App 内。
- 用户可以添加番剧/动画电影到资料库，记录观看状态
  - 未看、在看、已看、搁置
  - 起止日期
  - 精确到集的观看进度
  - 重看状态与重看次数
- 可以记录感想、评分
- 可以收藏喜欢的条目，并按收藏状态筛选或分组
- 搜索支持批量添加，可以按标题或 TMDb ID 一次添加多个条目
- 在列表和网格视图中可以多选条目，批量修改观看状态、评分、收藏和日期追踪，或批量删除
- 可以在 Infuse、Kazumi 或哔哩哔哩中打开条目，也可以打开条目主页
- 可以获取每集的摘要、声优等信息
- 可以查看番剧/动画电影在 TMDb 上的评分
- 可以查看符合条件番剧的播出时间，并为新番每集播出设置提醒，可以使用默认提醒时间，也可以为每部动画单独设置
- 可以通过 iCloud Sync 在多台设备间同步资料库、设置和观看进度
- 可以备份和恢复 AniShelf 资料库与设置，也可以将资料库导出为 TXT、CSV、TSV、JSON 或 XLSX 文件
- 动画信息支持英文、中文、日文显示
- 支持 iPhone、iPad，并提供原生 Mac 应用。在 iPad 和 Mac 上，每个窗口会独立保留各自的分类、筛选、排序和视图模式
- 精美的 UI 设计、流畅的交互体验

AniShelf 还提供配套的命令行工具 [anishelf-cli](https://github.com/samuelhe52/anishelf-cli)。开启 iCloud Sync 后，可以通过 `ani` 命令以只读方式访问 AniShelf 资料库。安装和使用方法请参阅 [anishelf-cli README](https://github.com/samuelhe52/anishelf-cli#readme)。

**它不是：**

- **在线追/看番工具（不提供下载链接或在线播放功能）**
- **小说/漫画阅读器（“书架”取比喻义，不是真的书架）**

当前暂时还没有：

- 与 TMDb/Bangumi/AniList 等平台观看数据同步功能

> 由于动漫信息依赖 TMDb API，其直连访问在部分网络环境下可能不稳定。App 默认直接访问 TMDb；如果搜索或元数据加载失败，可以在设置中开启“Use TMDb Proxy”，通过自建代理服务器请求 TMDb API。海报等图片资源不会经过该代理，仍可能因网络环境而加载失败。
> 如果你使用梯子或其他网络代理，通常建议保持“Use TMDb Proxy”关闭，直接访问 TMDb 可能更稳定、更快。

## 教程

### 申请 API Key

要使用 AniShelf，需要一个对个人使用免费的 TMDb API Key。请按照以下步骤申请：

1. 访问 [TMDb 官网](https://www.themoviedb.org/)，并注册一个账户。
2. 登录后，进入账户设置页面，找到 API 部分；或直接访问 [TMDb API 页面](https://www.themoviedb.org/settings/api/request)。
3. 选择 Personal Use/个人使用选项，并填写信息：
   1. 应用名称填写 "AniShelf"。
   2. 应用网址可以填写 TestFlight 链接 (https://testflight.apple.com/join/ns3sR38X)，或者 GitHub 仓库链接 (https://github.com/samuelhe52/AniShelf)。
   3. 使用类型选择 "Mobile Application"。
   4. 应用概述建议填“A digital bookshelf for your anime – track, organize, and revisit your favorite series with ease.”
   5. Contact Info 可以随便填；同意条款后点击 "Subscribe"。
4. 再次访问 [API 页面](https://www.themoviedb.org/settings/api)，在页面最下方，复制你的 API Key 并保存好。

### App 使用

1. 下载并安装 AniShelf App。
   1. 目前已上架 App Store，直接搜索 "AniShelf" 即可；或者直接点击链接： [App Store 链接](https://apps.apple.com/app/id6759359144)。
   2. 也可以加入 TestFlight 测试版，提前体验新功能：[AniShelf TestFlight](https://testflight.apple.com/join/ns3sR38X)。如果没有安装 TestFlight，需要先安装 TestFlight 应用，再重新访问链接，点击 "View in TestFlight"。
2. 如第一次打开，需要按提示输入 TMDb API Key。
3. 在应用内，点击右下方搜索按钮，输入番剧/动画电影名称，找到对应条目后可以添加到资料库。
   1. 对于番剧，可以选择添加整个系列，或者单独添加某一季（通过下面的滑块选择模式）。点击右上角的按钮即可选中系列/某一季（或多季），然后点击 "加入资料库"。
   2. 对于动画电影，直接选中后点击 "加入资料库" 即可。
   3. 有些番剧虽然从播出时间上来看是多季的，但动画官方并没有区分季的概念（集数是连续的）。典型的例子是芙莉莲，“第一季”包含了全部三十八集。遇到这种情况就只能选择添加整个系列了。
   4. 如果需要一次添加多个条目，可以点击搜索页面右上角的“批量添加”按钮，按标题或 TMDb ID 输入多个条目。
4. 点击左下角图标，可以切换不同的资料库视图。
5. 下方正中央的状态栏可以对展示的条目进行过滤，例如只显示“在看”状态的番剧/动画电影。
6. 双击主页面中的条目可以进入详情页，在那里可以查看条目的详细信息，并记录观看状态、起止日期、感想等信息。
   1. 点击详情页中“···”按钮，可以进行系列条目和单季条目互转，标记为中断/搁置等操作。
   2. 点击心形按钮可以收藏或取消收藏条目。
   3. 点击星星即可评分，再次点击当前评分的最后一颗星，可以在整星与半星评分之间切换；也可以在星星上拖动来调整分数。
   4. 点击“打开方式…”，可以在 Infuse、Kazumi 或哔哩哔哩中打开条目，或打开条目主页。未安装的 App 会显示为“未安装”。
   5. 点击分享按钮，可以生成一张用于安利的海报。
   6. 下滑可以查看摘要、声优、每集的摘要等信息。
   7. 符合条件的番剧会显示播出时间。对于正在连载的番剧，打开“···”菜单，选择“通知” > “开启”，即可为每集新番设置提醒。如需单独调整某部番剧的提醒时间，在同一菜单中选择“提醒时间”，关闭“使用默认设置”，再设置播出前或播出后的时间。
   8. 分集进度默认关闭，需要在设置的“资料库与追踪”中开启“记录分集进度”。开启后，条目处于“在看”状态时会显示分集进度。
   9. 想重看某部番时，把观看状态从“已看完”改为“在看”，在“是在重看吗？”提示中点击“开始重看”。这会清除分集进度，之后再次标为“已看完”时，重看次数会加 1。点击观看状态旁的标记，可以开启或关闭“重看中”，或者修改“重看次数”。
7. 长按主页面中的条目可以触发更多操作。在列表视图中，可以右滑/左滑条目来快速更新观看状态/删除条目。左滑后点击“打开”，或直接左滑到底，可以在其他 App 中打开条目；如果不想每次选择，可以在设置的“外观与交互”中设置“滑动操作打开”。
8. 在列表或网格视图中，点击右上角的“选择”可以进入多选模式，批量更改状态、评分、收藏和日期追踪，或批量删除条目。
9. 如需按自己的方式整理动画，可以在设置的“资料库与追踪”中开启“资料库分类”。
   1. 在多选模式中选中条目后点击“分类”，选择一个分类即可加入或移出这些条目；也可以点击“新建分类…”，用选中的条目新建分类。
   2. 点击资料库顶部的标题，或在状态栏菜单中使用“分类”，即可切换分类，“全部”会显示整个资料库。在标题菜单中选择“编辑分类…”，或在设置中点击“管理分类”，可以重命名、删除分类或调整顺序。删除分类不会把其中的动画移出资料库。
   3. 开启“固定分类栏”后，列表和网格视图会在导航栏下方固定显示分类标签。长按标签可以重命名或删除分类，也可以选择“调整标签顺序”，拖动标签后点击“完成”。
10. 点击右上角的设置图标可以进入设置页面。页面上方显示资料库统计，下方是六组设置：“语言”“资料库与追踪”“外观与交互”“播出与提醒”“元数据与图片”和“同步与数据”。
   1. 如需在多台设备间同步资料库、设置和观看进度，请在“同步与数据”中手动开启 iCloud 同步，并确保各设备登录同一个 Apple 账户。
   2. 在“同步与数据”中，“备份”会将资料库与设置保存为 `.mallib` 文件（不包含 TMDb API Key），“恢复”会用备份覆盖当前资料库。恢复前请先关闭 iCloud 同步。“导出为…”可以将资料库导出为常用文件格式，但这些文件不能用来恢复。
   3. 在“语言”中关闭“跟随系统”，即可为动画信息选择英文、中文或日文。在“默认海报”中选择“跟随动画信息语言”，TMDb 有对应语言的海报时就会优先使用。这些更改只对之后获取的信息生效，如需更新现有条目，请在提示时点击“刷新”，或者之后点击“刷新信息”；手动选择的海报会保留。“刷新信息”位于“元数据与图片”，TMDb 代理、API 密钥和缓存操作也在这里。
   4. 在“播出与提醒”中可以设置所有提醒的“默认提醒时间”；点击“提醒”可以查看每条提醒、修改提醒时间或移除提醒。
11. 在 Mac 上，AniShelf 是原生应用：资料库范围和分类位于侧边栏，选中条目后，详情会显示在资料库旁的检查器中。选择“文件” > “新建窗口”可以打开新窗口；在 iPad 和 Mac 上，每个窗口会独立保留各自的分类、筛选、排序和视图模式。

## 常见问题

- TMDb API 是什么？API Key 是什么？**AniShelf 使用 TMDb API 来获取番剧/动画电影的数据，例如标题、简介、海报等信息。TMDb API Key 是你从 TMDb 官网申请的一个密钥，用来授权 AniShelf 访问 TMDb 的数据。因为本 App 完全免费，故不提供公用的 API Key，用户必须按照教程自行申请**
- API Key 验证不通过？加载缓慢，搜索不到结果？**可以分别尝试开启或关闭梯子，因为不同网络代理的规则可能影响访问。App 默认直连 TMDb；若直连不稳定，可以在设置中开启“Use TMDb Proxy”。如果已在使用梯子或其他网络代理，通常建议保持该选项关闭。**
- 如何在多台设备间同步资料库？**在设置中手动开启 iCloud Sync，并确保各设备登录同一个 Apple 账户。它会同步资料库、相关设置和观看进度；与 TMDb、Bangumi、AniList 等平台的观看数据同步暂未支持。**
- 找不到分集进度？**分集进度默认关闭，请在设置的“资料库与追踪”中开启“记录分集进度”。详情页只有在条目处于“在看”状态时才会显示分集进度。**
- 无法恢复资料库？**请先关闭 iCloud 同步，恢复完成后再重新开启。只有 `.mallib` 备份文件可以恢复，通过“导出为…”生成的 TXT、CSV、TSV、JSON、XLSX 文件不能用来恢复。**
- 弹出“解决 iCloud 同步冲突”时该怎么选？**开启或重建 iCloud 同步时，如果同一部动画在这台设备和 iCloud 中的数据不同，就会出现这个提示。“使用 iCloud”会保留这些条目在 iCloud 中的版本；“使用这台设备”会保留这台设备上的版本并上传到 iCloud；“取消”会关闭 iCloud 同步，资料库保持不变。无论选哪一项，只存在于一边的动画都会保留。**
- iCloud 同步出错，或显示同步问题？**在设置中点击 iCloud 同步状态旁的“重试”。如果出现橙色的同步问题提示，点击即可查看原因；TMDb 上已不存在的条目可以在那里从 iCloud 删除。如果问题仍然存在，可以在设置中点击“重建 iCloud 同步”，重新获取 iCloud 资料库并与这台设备重新同步。**
- 如何反馈 Bug/功能建议？**欢迎通过 GitHub Issues 反馈 Bug 或者提出功能建议。也可以在群里讨论，我会不定期的查看**
- 是否会上架 App Store？**已经上架。[App Store 链接](https://apps.apple.com/app/id6759359144)。大多数情况下，新功能仍然将先在 TestFlight 发布，后续再推送到 App Store。**
- 是否支持 26 以下系统？**目前不支持。App 中使用了大量液态玻璃效果，iOS、iPadOS 和 macOS 26 以下系统不支持。并且我手上也没有 26 以下系统的测试机，如果有愿意做内部测试的同学，可以私信我，我可以尝试做适配，但是 UI 美观性应该会差一些**
- 是否支持安卓/鸿蒙？**暂时没有这方面计划～**
