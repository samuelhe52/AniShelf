# AniShelf product poster

A version-neutral, 1920×1080 Remotion poster presenting AniShelf's core product experience in Chinese.

## Preview

```bash
npm install
npm run dev
```

Open the `AniShelf-Overview-Poster-ZH` still composition.

## Render

```bash
npm run render
```

The rendered PNG is written to `out/AniShelf-Overview-Poster-ZH.png`. Rendered output is intentionally excluded from Git.

## Assets

The project keeps its app icon and source screenshots under `public/` so it remains self-contained. The screenshot copies originate from the canonical assets in `../screenshots/ios/`.
